# Code of Conduct

OpenCoach contributors must maintain a respectful, technically rigorous, and welcoming environment.

## Expected behavior

- Discuss ideas and code without personal attacks.
- Give actionable, evidence-based review feedback.
- Respect privacy and do not publish another person's credentials, recordings, identifiers, or private correspondence.
- Clearly distinguish verified results from assumptions and untested claims.
- Credit upstream projects and contributors.

## Unacceptable behavior

Harassment, discrimination, threats, deliberate disclosure of private information, credential abuse, and knowingly falsified test or security evidence are not tolerated.

## Enforcement

Report conduct concerns privately to the repository owner through an appropriate private GitHub channel. Security vulnerabilities must use the process in `SECURITY.md`. The maintainer may edit, hide, reject, or remove contributions and participation that violate this policy.

This policy applies in project repositories, issue trackers, reviews, discussions, and project-related community spaces.
