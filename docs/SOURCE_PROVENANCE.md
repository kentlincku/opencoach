# Public source provenance

The initial OpenCoach public tree was curated from the private Voice Practice Unified development snapshot:

```text
SOURCE_SNAPSHOT_SHA=7b0874f1a25996a55a14a3afbe98e9d1ab726c47
```

The public repository intentionally starts with a new Git history. Private development evidence, machine paths, obsolete task packets, generated artifacts, and superseded experiments were not imported.

This provenance identifier records the source snapshot only. It does not claim that every platform release gate passed at that commit. Current public support and release boundaries are documented in `docs/RELEASE_STATUS.md`.
